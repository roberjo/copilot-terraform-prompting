# Examples

This folder will contain minimal, focused Terraform examples for each in-scope AWS resource and a combined example that mirrors the live demo.

## Examples
- `s3/`
- `iam/`
- `lambda/`
- `api-gateway/`
- `api-gateway-custom-domain/`
- `security-groups/`
- `route53-a-record/`
- `full-stack/` (end-to-end demo)
- `modules/` (basic modularization example)

See `examples/examples-index.md` for a short description of each example.
